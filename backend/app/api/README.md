# TrackXpense API Documentation

## Available Endpoints

### Root Endpoint
- `GET /` - Returns basic API information

### Finance GPT Endpoints
- `POST /api/v1/finance-gpt` - Process financial chat messages

### Health Check
- `GET /health` - Check API health status

## API Documentation
- Interactive API documentation: `/docs`
- ReDoc documentation: `/redoc`

## Error Handling
- 404: Returns JSON with error details
- 500: Returns JSON with error information
