# Library Directory

This directory contains utility functions, services, and helpers used throughout the TrackXpense application.

## Files

- **auth.ts**: Authentication utilities
- **category-utils.ts**: Expense category utilities
- **chart-utils.ts**: Chart and data visualization utilities
- **colors.ts**: Color definitions and utilities
- **constants.ts**: Application constants
- **db-utils.ts**: Database utilities
- **db.ts**: Database connection and types
- **expense-utils.ts**: Expense data utilities
- **firebase-admin.ts**: Firebase Admin SDK utilities
- **firebase.ts**: Firebase client SDK utilities
- **server-auth.ts**: Server-side authentication utilities
- **toast.ts**: Toast notification utilities
- **utils.ts**: General utility functions
- **validation.ts**: Form validation utilities

## Subdirectories

- **services/**: Service classes for API interactions and data processing
