# Services Directory

This directory contains service classes that handle API interactions, data processing, and external service integrations.

## Files

- **category-predictor.ts**: Service for predicting expense categories
- **notification-service.ts**: Service for managing notifications
- **ocr-service.ts**: Service for optical character recognition (OCR) of receipts
- **postgres-storage-service.ts**: Service for storing data in PostgreSQL
- **socket-service.ts**: Service for WebSocket connections
- **storage-service.ts**: Service for file storage
