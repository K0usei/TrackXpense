GUIDE ON HOW "TRACKXPENSE" WORKS:

1. User Authentication (Login/Sign-Up)
- When the app is opened, users are greeted with the **TrackXpense** splash screen.
- The user is then directed to the **Login/Sign-Up** screen.
  - If they have an account, they enter their **email** and **password** and click **Login**.
  - If they forget their password, they can click **Forgot Password** to reset it.
  - Provide proper validation for email and password (error messages for invalid inputs)
  - There's an option where they can login with their Google accounts.
  - If they don’t have an account, they click **Sign Up**, which takes them to a registration form.
- In the **Sign-Up** form:
  - The user enters their **email**, **password**, and **confirms** the password.
  - They provide their **monthly budget** and **monthly income** details. (users also must select currency type when entering monthly budget and monthly income)
    - The app also validates the **password** to ensure it meets the required criteria.(error messages for invalid inputs)
    - The app also validates the **email** to ensure it's a valid email address.(error messages for invalid inputs)
    - The app also validates the **monthly budget** and **monthly income** to ensure it's a valid number.
  - Clicking **Confirm** completes the registration, and they can proceed to the dashboard after logging in.
- The app should be in **dark mode** by default.
- Add animations for smooth transitions between screens.
- Add a **loading screen** during authentication and data loading.
- Ensure that the app is **responsive** and works well on different screen sizes.

2. Dashboard & Navigation
- After logging in, the user is directed to the **Dashboard**, which shows:
  - A **donut chart** summarizing expenses per categories and **bar graph** for visualization of summarized statistics like **total expenses**, **monthly budget**, and **remaining balance**.
  - Navigation icons at the bottom for **home** (Dashboard), **Activity reports**, **Receipt Scanner**,**AI chatbot**, and **Budget report**.
- The user can access the **menu** via a hamburger icon located at the top right corner of the screen("TrackXpense" logo at the top left corner). It allows them to:
  - Manage their account.
  - Edit personal information.(includes editing of monthly budget and monthly income)
  - Toggle **dark mode**.
  - View **receipts gallery**.
  - Check **notifications**.
  - Logout.

Step-by-Step Development Guide for TrackXpense

1. Project Setup & Environment Configuration
Frontend Setup (Next.js, TailwindCSS, ShadCN UI)
1. Initialize Next.js Project
   npx create-next-app@latest trackxpense
   cd trackxpense
2. Install Dependencies
   npm install tailwindcss postcss autoprefixer @shadcn/ui recharts
3. Configure TailwindCSS
   npx tailwindcss init -p
   - Edit `tailwind.config.js` to include ShadCN UI components.
4. Set up PWA support
   npm install next-pwa
   - Configure `next.config.js` for PWA support.

Backend Setup (FastAPI, Firebase, PostgreSQL, Redis)
1. Initialize FastAPI project
   mkdir backend && cd backend
   python -m venv venv
   source venv/bin/activate  # For Linux/macOS
   venv\Scripts\activate  # For Windows
2. Install Dependencies
   pip install fastapi uvicorn firebase-admin sqlalchemy psycopg2 redis
3. Set up Firebase Authentication
   - Generate a service account key from Firebase and configure authentication.
4. Set up PostgreSQL Database
   CREATE DATABASE trackxpense;
   - Use SQLAlchemy ORM for database interaction.
